# Phase 9: External references and related projects

This document collects external projects that are useful as reference for the Linux port and for future modding functionality. They are not part of the codebase; they are reference documentation.

---

## 1. dw_decomp (submodule `decomp/`)

**Path:** `/home/oar/pro/dw1-linux/decomp/` (submodule of dw1-silicon)  
**Upstream:** https://github.com/jype0/dw_decomp  
**License:** MIT

It is the "matching" decompilation of Digimon World. Provides the readable and editable C source of the game. All game modification work is done here.

- **Role in this project:** Editable C source for game logic.
- **What to edit:** `decomp/src/` for game changes; `decomp/text/` for texts.
- **What not to edit:** `asm/`, `build/`, `assets/`, `disks/` (generated by build).

---

## 2. psxrecomp (reference for mods)

**Path:** `/home/oar/pro/psxrecomp`  
**Upstream:** https://github.com/mstan/psxrecomp  
**License:** PolyForm Noncommercial 1.0.0 (non-commercial use)

It is a static PS1 recompiler that converts PS1 games into native PC executables (Linux/Windows/macOS). It has a versioned mod system called `.psxmod`.

**Why it is useful as reference:**
- Guarded byte patches (`expected` + `replace`).
- Asset overlays with SHA-256 hash (does not rewrite user's disc).
- Trusted C plugins for custom behavior.
- Live language switching with TOML tables.

**How to use it here:**
- It is not the codebase of this port (dw1-silicon already is).
- Serves as inspiration if in the future you want a versioned mod system for dw1-linux.
- Key documentation: `docs/MOD_PACKAGES.md` in psxrecomp.

## 3. DW2-PC (PC architecture template)

**Upstream:** https://github.com/Wyrelade/DW2-PC  
**License:** CC0

It is a native port of Digimon World 2 for Windows/Linux, built from its own decompilation. dw1-silicon explicitly cites it as its design template.

**Reference structure:**
```
src/          → Game C (with 64-bit fixes)
psyq/         → PC versions of Psy-Q libraries
backend/      → GPU, SPU, XA, MDEC
host/         → SDL3 window, input, audio, cards, data pack
tests/        → GTE and hardware tests
```

**Why it is useful:**
- It is the closest model to what you want: a native PC port of a Digimon game.
- Shows how to organize a Rust + C project for Linux/Windows.
- dw1-silicon reuses its hardware models (GTE, GPU, SPU, XA, MDEC) translated to Rust.

## 5. How to use these references

1. **To edit the game:** Work in `decomp/src/` (dw_decomp C).
2. **To understand the PS1 SDK:** Consult `dw1-silicon/docs/survey.md` (175 SDK calls).
3. **For mod system ideas:** Read `psxrecomp/docs/MOD_PACKAGES.md`.
4. **To organize the project long-term:** Look at `DW2-PC` structure.
